### QQAIChatEx - 在你的QQ群内接入AI吧~ v0.0.8
- **加载模式**: bds | **优先级**: post | **权限**: core

在你的 QQ 群内接入 AI 吧~ 功能丰富：

#### 主要特性
- **多模型支持** - 主模型 + 回退模型 + 外置视觉模型，自动容灾
- **工具调用** - 支持 AI 调用联网搜索、语音合成、发送音乐卡片等工具
- **知识库** - 内置 CQ 码知识库，AI 可搜索查询
- **消息防抖** - 合并短时间内多条消息，节省 Token
- **自动分段** - AI 回复自动分段发送，更接近真人聊天
- **记忆系统** - 支持对话记忆、压缩、清除和备份
- **Token 统计** - 可显示每次对话的 Token 消耗明细
- **系统提示词** - 支持自定义 /aichat 指令热切换
- **配置热重载** - 通过指令在线修改配置

#### 命令
- `/aichat memory` - 记忆管理（重载/压缩/删除/设置提示词）
- `/aichat tool` - 手动调用工具
- `/aichat config` - 热更改临时配置

#### 触发方式
- 关键词触发（默认：`兮兮`）
- @机器人触发
- 私聊自动响应

### QQDebug - 在QQ群内在线调试吧~ v0.0.1
- **加载模式**: bds | **优先级**: post | **权限**: core

如果你觉得在 sb3 插件开发时，反复重载/敲一大串 jsdebug 太麻烦的话，可以试试这个插件！

此插件适用于 sb3 开发者，如果你是普通用户，可以下来玩玩，但一定要处理好权限关系。
插件使用 core 权限，请注意好隐私管理！

#### 命令参数
- `--debugdata` - 查看调试信息结构
- `--reply` - 查看引用的消息元数据
- `--msgdata` - 查看当前群聊信息
- `--sendmsg` - 发送 CQ 码消息
  - `--file2base64` - 把 `${}` 包裹的路径解析为 base64
  - `--rawmsg` - 查看这条 CQ 码消息的解析

## 使用说明

每个插件都包含相应的配置文件 (`spark.json`) 和实现文件 (`index.js`)，请按照 SparkBridge3 框架的要求进行安装和配置。

将对应插件文件夹放入 SparkBridge3 的 `plugins/` 目录下，确保 `spark.json` 中的配置正确，然后重载插件即可。

部分插件支持网页管理面板配置，可在 SparkBridge3 的网页后台中修改。
